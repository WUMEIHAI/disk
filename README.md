# 整数磁盘分区计算器

一个纯前端的磁盘分区辅助工具：输入期望的分区大小（GB），自动计算出**按 CHS 柱面对齐后的精确 MB 数值**，供分区时直接填写，避免出现 `xxx.9 GB` 这类不规整的容量显示。

- **项目类型**：静态单页应用（HTML + CSS + 原生 JavaScript）
- **入口文件**：`index.html`
- **构建依赖**：无。双击 `index.html` 用浏览器打开即可运行
- **第三方资源**：Tailwind CSS、Font Awesome（均通过 CDN 引入，需联网）

---

## 项目简介与用途

在 Windows 磁盘管理或分区助手中新建分区时，直接按 `1 GB = 1024 MB` 填整数，系统实际显示往往会是 `99.9 GB`、`199.9 GB` 这种带零头的结果。原因是传统分区需要对齐**柱面（Cylinder）**边界，而一个柱面的大小并不是整数 MB。

本工具把这个换算自动化：你给出**想要多大的分区**，它反推出**应该填多少 MB**，让最终容量最接近你的预期且符合柱面对齐规则。

核心算法（CHS：255 磁头 × 63 扇区 × 512 字节）：

```
单柱面大小 = 512 × 255 × 63 / 1024 / 1024 ≈ 7.844238 MB

总 MB     = GB × 1024
柱面数    = ceil(总 MB / 7.844238)      // 向上取整，保证不小于期望值
最终 MB   = 柱面数 × 7.844238           // 保留两位小数
```

例如输入 `100 GB`：102400 MB → 13055 个柱面 → **102406.53 MB**。

## 核心功能

| 功能 | 说明 |
|---|---|
| **分区数值计算** | 输入 GB 值，输出符合柱面对齐规则的 MB 值（保留两位小数） |
| **快捷规格选择** | 一键填入 10 / 20 / 30 / 50 / 100 / 200 / 500 GB 与 1 TB 常用规格，并立即计算 |
| **计算过程详解** | 展开展示「GB→MB」「求柱面数」「反推 MB」三步推导，结果可复核 |
| **一键复制结果** | 将最终 MB 数值复制到剪贴板，直接粘贴到分区工具 |
| **输入记忆** | 借助 localStorage 记住上次输入的 GB 值，刷新后自动恢复 |
| **Toast 提示** | 操作反馈、校验错误以浮层提示呈现，3 秒后自动消失 |
| **响应式布局** | 桌面端左右分栏，移动端自动堆叠；窄屏计算后自动滚动到结果区 |

### 输入校验

- 未输入或非正数时，提示「请输入有效的正数」并终止计算
- 支持小数输入，按数值参与计算（结果仍按柱面取整）

### 关键文件说明

**`index.html`** 由四部分组成：

1. **`<head>` 配置区** —— 引入 CDN 资源，并通过 `tailwind.config` 扩展自定义主题色（`primary` / `secondary` / `success` 等）与字体。
2. **自定义 `<style>`** —— 全局字体与背景、`.input-group:focus-within` 聚焦联动、`.result-card` 渐变、滚动条美化、`.transition-all-300` 过渡类。
3. **页面结构** —— 顶部导航、左侧「分区设置」输入卡（含快捷按钮与操作按钮）、右侧结果展示卡与初始占位图、页脚、Toast 容器。
4. **脚本逻辑** —— 常量 `CYLINDER_SIZE_MB`、`calculate()` 核心计算、`updateResultUI()` 结果渲染、`copyResult()` 复制、`showToast()` 提示系统。

### 主要函数

| 函数 | 作用 |
|---|---|
| `calculate()` | 核心计算入口：读取输入 → 校验 → 三步换算 → 渲染结果 → 切换结果区显示 |
| `updateResultUI(inputGB, outputMB, rawMB, cylCount)` | 填充输入值、输出值及三步推导文本 |
| `handleInput(val)` | 输入时实时保存当前值到 localStorage |
| `setGB(val)` | 快捷按钮：填入数值并立即计算 |
| `resetForm()` | 清空输入、隐藏结果区、清除已保存的输入值 |
| `copyResult()` | 复制结果数值到剪贴板 |
| `showToast(message, type)` | 显示 info / success / error 三种样式的浮层提示 |
| `toggleTheme()` | 主题切换占位（演示，暂未实现深色模式） |

## 本地运行方式

### 方式一：直接打开（最简单）

双击 `index.html`，或右键选择浏览器打开即可。

### 方式二：本地 HTTP 服务

若希望以 HTTP 协议访问（便于手机同局域网调试，或避免个别浏览器的本地文件限制），在项目根目录执行：

```bash
# Python 3
cd D:\disk
python -m http.server 8000
# 浏览器访问 http://localhost:8000

# Node.js
npx serve .
```

### 部署

将 `index.html` 上传到任意静态托管（Nginx、GitHub Pages、对象存储、Vercel 等）即可，无需构建步骤。

## 注意事项

1. **单位约定为二进制**：本项目按 `1 GB = 1024 MB` 计算。硬盘厂商标称容量通常用 `1 GB = 1000 MB`，两者存在差异属正常现象。
2. **结果为理论值**：CHS 是传统柱面寻址模型。现代硬盘与 SSD 普遍使用 LBA 寻址，Windows 安装程序或 DiskPart 通常会自行做 4K / 1MB 对齐，实际分区时以工具给出的值为准即可，本工具主要用于快速估算与核对。
3. **主题切换为占位功能**：头部月亮按钮目前仅弹出「深色模式开发中」提示，未实际实现深色模式。
4. **浏览器兼容性**：使用了 `navigator.clipboard`、`scrollIntoView({behavior:'smooth'})` 等较新 API，建议使用近两年的 Chrome / Edge / Firefox / Safari。剪贴板 API 在非 HTTPS、非 localhost 环境下可能被浏览器拒绝。
